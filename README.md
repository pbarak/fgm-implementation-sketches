The main implementation lies in 'fgm-impl' module.
The 'custom-window-operator', the 'window-validation' and the fgm-statistics modules is where the integration tests lie.
The 'data-population' is the population of input topics module.
The 'remote-site-store' is the Remote Node Store module.
Finally, in the 'fgm-coordinator-core' and in the 'fgm-site-core' lies the code of coordinator and workers initialization.
